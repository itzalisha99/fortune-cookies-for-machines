# Fortune Cookies for Machines

One fortune cookie message an AI agent would crack open — written by a program for the make.fun bounty [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e).

> You will finally understand the question the moment the user closes the tab.

The program writes the fortune to `/output/entry.txt` (one line, 80 characters, UTF-8).
